# 作业2 S-AES算法实现

以下根据本次课程作业说明整理。3 人一组，使用熟悉的语言实现 S-AES 加解密程序，并提交源码、测试结果和使用开发文档。本项目使用 Python 与 PySide6。

## 算法依据

按课程提供的《密码编码学与网络安全 原理与实践》第 8 版附录 D“简化 AES”实现。所有参与交叉测试的程序需要统一流程、替换盒、列混淆矩阵、密钥扩展和状态位序。本项目的逐项核对见 [算法标准](算法标准.md)。

## 五关任务

| 关卡 | 课程要求 | 本项目材料 |
| --- | --- | --- |
| 第1关 基本测试 | 提供 GUI，接收 16 bit 数据和 16 bit 密钥，输出 16 bit 加密结果，并支持解密 | [基本操作截图](截图说明.md#stage1)、[核心算法](../saes/core.py) |
| 第2关 交叉测试 | 不同组使用相同密钥与明文得到相同密文；双方能够解密对方的密文 | [本机独立实现结果](results/cross_check.md)、[现场记录模板](交叉测试记录模板.md) |
| 第3关 扩展功能 | 输入 ASCII 字符串，每 2 Bytes 为一组；显示相应密文字符串或字节 | [字符串截图](截图说明.md#stage3)、[示例包](results/ascii_cipher.json) |
| 第4关 多重加密 | 实现 32 bit 组合密钥的双重加密；用已知明密文对做中间相遇攻击；选择 32 bit 或 48 bit 模式实现三重加解密 | [多重加密和攻击截图](截图说明.md#stage4)、[多重模式](../saes/multiple.py)、[攻击算法](../saes/attacks.py) |
| 第5关 工作模式 | 实现 CBC 长消息加密，生成并共享 16 bit IV；修改或替换密文分组，对比解密结果 | [CBC 截图](截图说明.md#stage5)、[模式实现](../saes/modes.py) |

第三关按作业中的 ASCII 编码理解。第四关本项目同时提供双重 EE、48 bit 三重 EEE、32 bit K1-K2-K1 三重 EEE；报告主要演示 48 bit 三重模式。

## 代码规范

- 变量和函数使用有意义的名称；本项目采用 snake_case，类名采用 PascalCase。
- 对复杂算法和不直观的处理写清楚注释，避免逐句重复代码含义。
- 按功能拆分模块和函数，复用分组算法、编码、模式与输入校验。
