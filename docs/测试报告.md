## 第1关 基本测试

输入明文 `6F6B`、密钥 `A73B`，加密得到 `0738`，再用相同密钥解密恢复 `6F6B`。轮密钥为 `A73B`、`1C27`、`7651`。第 1 轮行移位后的状态是 `C916`，对应矩阵 `[C 1;9 6]`。

教材密钥扩展 `2D55 → BCE9 → A34A`、正逆 S 盒和基本变换算例单独核对；还检查了 10000 组往返，以及固定密钥下全部 65536 个明文的输出唯一性。

证据：[加密](../截图与视频/第1关_加密.png)、[解密](../截图与视频/第1关_解密.png)、[逐轮状态](../截图与视频/第1关_逐轮状态.png)、[算法标准](算法标准.md)。

## 第2关 交叉测试

独立 C++ 实现使用数组状态与独立有限域乘法，Python 使用整数状态。脚本实际编译并运行 C++，比较加密结果、任意密文的解密结果以及双方互解，共 1005 组全部通过。界面截图载入了实际 C++ 输出整理的 1005 组向量。

这属于本机两种语言的独立实现互测。另一小组的现场互测仍需实际交换数据并填写 [记录模板](交叉测试记录模板.md)。

## 第3关 ASCII 字符串

`Hello, S-AES!` 共 13 字节，按两字节分为 7 组，最后补一个零字节。使用 `A73B` 加密后得到：

```text
2B91 7F2D 7CBD BBB5 2F04 658A 472C
```

JSON 保存原长度；清空原文或在新窗口导入后，仍可还原原来的字符串。自动测试覆盖空串、奇数长度、末尾空字节和换行，非 ASCII 输入会被拒绝。

证据：[加密截图](../截图与视频/第3关_字符串加密.png)、[解密截图](../截图与视频/第3关_字符串解密.png)、[密文包](results/ascii_cipher.json)。

## 第4关 多重加密与中间相遇

| 模式 | 密钥 | 明文 | 密文 | 解密 |
| --- | --- | --- | --- | --- |
| 双重 EE / 32 bit | `1F2E3D4C` | `6F6B` | `FE80` | `6F6B` |
| 三重 EEE / 48 bit | `1F2E3D4C5A6B` | `6F6B` | `5AF9` | `6F6B` |
| 三重 EEE / 32 bit | `1F2E3D4C` | `6F6B` | `FF78` | `6F6B` |

中间相遇攻击完整枚举 K1、K2 各 65536 个值。单组 `(6F6B,FE80)` 得到 65423 个候选；增加 `(1234,69D8)` 和 `(BEEF,093D)` 后，只留下 `1F2E3D4C`。

实际界面截图中的三对搜索耗时为 **1.71 秒**。自动验证会另行运行单对和三对搜索，其合计耗时见 [自动验证记录](results/五关测试结果.md)。自动测试还检查碰撞保留、矛盾已知对、取消和前导零密钥。

证据：[双重加密](../截图与视频/第4关_双重加密.png)、[双重解密](../截图与视频/第4关_双重解密.png)、[攻击结果](../截图与视频/第4关_中间相遇攻击.png)、[三重加密](../截图与视频/第4关_三重加密.png)、[三重解密](../截图与视频/第4关_三重解密.png)。

## 第5关 CBC 与篡改实验

使用 `K=A73B`、`IV=1357`，加密 22 字节的 `Hello, S-AES CBC mode!`：

```text
84A5 D154 0B0C F821 14B7 5C5C 868D 9D22 AF0B 1E84 FD4E
```

接收方从密文包读取 IV 和原长度，可以恢复原文。两次篡改均从原始包的副本开始：

| 操作 | 当前明文分组 | 下一明文分组 | 后续 |
| --- | --- | --- | --- |
| C1：`84A5 → 84A4` | P1：`4865 → 8869` | P2：`6C6C → 6C6D`，XOR 差值 `0001` | P3 起相同 |
| C2：`D154 → 0000` | P2：`6C6C → A217` | P3：`6F2C → BE78`，XOR 差值 `D154` | P4 起相同，P1 也未变 |

结果符合 CBC 的传播规律。自动测试还覆盖任意位置翻转、替换、修改 IV 和空消息。CBC 没有认证功能，不能仅凭解密后的内容判断密文是否完整。

证据：[加密](../截图与视频/第5关_CBC加密.png)、[解密](../截图与视频/第5关_CBC解密.png)、[翻转](../截图与视频/第5关_翻转密文.png)、[替换](../截图与视频/第5关_替换分组.png)、[密文包](results/cbc_cipher.json)、[逐组差值](results/五关测试结果.md)。

## 如何重新验证

在项目根目录运行：

```powershell
python -X utf8 tools/verify.py
.venv\Scripts\python -X utf8 tools/gui_smoke.py --offscreen
python tools/check_repository.py
```

第一条包含 30 项单元测试和五关数据生成；C++ 互测需要 `g++`，缺失时会记录为未执行。第二条需先安装 Qt 依赖；离屏检查不生成用于报告的桌面截图。结果文件的用途见 [原始记录索引](results/README.md)。
