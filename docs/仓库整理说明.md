# 仓库目录与文件整理说明

目录组织参考 [Information_Security_Lab1](https://github.com/Qisheng-Zhang/Information_Security_Lab1)：根目录保留源码包、测试、README 和运行入口，文档放入 docs，演示素材放入“截图与视频”，首页按五关链接到实际证据。

## 现在各类文件放在哪里

| 位置 | 内容 |
| --- | --- |
| `saes/` | 当前 Python 源码，算法、模式、攻击、Qt 布局和事件分开 |
| `tests/` | 单元测试与独立 C++ 参考实现 |
| `tools/` | 验证、GUI 检查、仓库检查和打包脚本 |
| `docs/` | 作业要求、算法标准、用户指南、开发手册、测试报告、截图说明、Word 报告和现场互测模板 |
| `docs/results/` | 原始测试日志、CSV、JSON 示例数据 |
| `截图与视频/` | 当前 15 张实际桌面原图，按关卡命名；目前没有录制视频 |
| `本地归档/` | 历史版本和制作过程，仅在本机保留 |
| `.venv/` | 本机虚拟环境，可由启动脚本重新准备 |
| `build/` | C++ 编译产物、GUI 临时数据与打包验证目录 |
| `dist/` | 最新交付 ZIP，由打包脚本生成 |

继续保留 `docs/results` 和源码包名 `saes`，这样测试命令、程序导入和 Word 报告内提到的路径仍能使用。没有为整理目录而移动算法模块。

## 文档入口和检查

[项目首页](../README.md) 按“任务、结果、运行、目录”组织；[文档导航](README.md) 按阅读目的查找材料；[截图说明](截图说明.md) 逐张解释操作；[测试报告](测试报告.md) 汇总结果并链接到原始记录。

```powershell
python tools/check_repository.py
python tools/package_release.py
```

检查脚本核对本地 Markdown 链接、五关所需原图、CSV/JSON 及 Word 报告。打包脚本使用固定的项目目录清单，生成 `dist/S-AES-Studio-2.2.zip`，不把归档、虚拟环境、缓存和编译产物收入包内。

上传 GitHub/Gitee 时，可以解压这个 ZIP 后上传其中的项目文件。使用 Git 提交时，根目录的 `.gitignore` 会排除本机资料；无需上传 `本地归档`、`.venv`、`build` 或 `dist`。打包文件内保留相对目录，解压后从根目录运行启动脚本。
