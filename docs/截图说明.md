# 五关实际截图与操作说明

以下 15 张图来自 S-AES Studio 2.2（PySide6 / Qt）的实际桌面操作。按表格中的输入和操作，可以逐项复现。[Word 实验报告](S-AES实验报告_截图演示版.docx)将这些画面与说明排在一起，关键结果另有局部放大。所有原图在根目录 [截图与视频](../截图与视频/README.md)。

数值默认按十六进制读取，前导零需要保留。

<a id="stage1"></a>
## 第1关 基本加解密

| 原图 | 输入与操作 | 看什么 |
| --- | --- | --- |
| [第1关_加密.png](../截图与视频/第1关_加密.png) | 输入 P=`6F6B`、K=`A73B`，点“加密” | 结果 `0738`，轮密钥 `A73B/1C27/7651` |
| [第1关_解密.png](../截图与视频/第1关_解密.png) | 点“回填”，使用相同密钥点“解密” | `0738` 还原为 `6F6B` |
| [第1关_逐轮状态.png](../截图与视频/第1关_逐轮状态.png) | 再次加密，选中第1轮“行移位” | 状态 `C916`，矩阵第一行 C、1，第二行 9、6 |

这三张图展示同一组数据的加密、解密和过程查看。矩阵跟随选中的步骤变化；输入更新后需要重新运算。

## 第3关 ASCII 字符串

| 原图 | 输入与操作 | 看什么 |
| --- | --- | --- |
| [第3关_字符串加密.png](../截图与视频/第3关_字符串加密.png) | 输入 `Hello, S-AES!`、K=`A73B`，点“加密” | 13 字节分为 7 组，JSON 保存原长度，RAW 区显示实际密文字节 |
| [第3关_字符串解密.png](../截图与视频/第3关_字符串解密.png) | 清空左侧原文，保留右侧密文包，点“解密” | 重新还原 `Hello, S-AES!`，提示“已还原” |

最后一组补一个零字节。因为包中记录原长度，解密时可以准确去掉补齐部分；不可打印密文字节用 `\xHH` 显示。可导入 [示例密文包](results/ascii_cipher.json) 复现解密。

<a id="stage4"></a>
## 第4关 多重加密与中间相遇攻击

| 原图 | 输入与操作 | 看什么 |
| --- | --- | --- |
| [第4关_双重加密.png](../截图与视频/第4关_双重加密.png) | 选“双重 / 32 bit”，K=`1F2E3D4C`、P=`6F6B`，点“加密” | 密文 `FE80` |
| [第4关_双重解密.png](../截图与视频/第4关_双重解密.png) | 回填 `FE80`，模式与密钥不变，点“解密” | 明文 `6F6B` |
| [第4关_中间相遇攻击.png](../截图与视频/第4关_中间相遇攻击.png) | 输入下面三组已知对，点“开始完整搜索” | 1 个候选 `1F2E3D4C`，该次用时 1.71 秒 |
| [第4关_三重加密.png](../截图与视频/第4关_三重加密.png) | 选“三重 / 48 bit”，K=`1F2E3D4C5A6B`、P=`6F6B`，点“加密” | 密文 `5AF9` |
| [第4关_三重解密.png](../截图与视频/第4关_三重解密.png) | 回填 `5AF9`，模式与密钥不变，点“解密” | 明文 `6F6B` |

中间相遇攻击使用的已知对：

```text
6F6B FE80
1234 69D8
BEEF 093D
```

攻击针对双重加密。三重加解密的截图右侧保留了前一步的双重攻击结果，三重模式的输入和输出看左侧。截图中的 1.71 秒只对应这次三对搜索，自动验证中的计时另行记录。

## 第5关 CBC 与篡改对比

| 原图 | 输入与操作 | 看什么 |
| --- | --- | --- |
| [第5关_CBC加密.png](../截图与视频/第5关_CBC加密.png) | 输入 `Hello, S-AES CBC mode!`、K=`A73B`、IV=`1357`，点“加密” | 22 字节、11 组，包内保存共享 IV |
| [第5关_CBC解密.png](../截图与视频/第5关_CBC解密.png) | 清空原文后点“解密” | 还原消息，状态栏显示使用包内 IV |
| [第5关_翻转密文.png](../截图与视频/第5关_翻转密文.png) | 分组编号 1，选“异或翻转”，掩码 `0001`，点“对比解密” | P1 改变，P2 的 XOR 差值为 `0001`，P3 起相同 |
| [第5关_替换分组.png](../截图与视频/第5关_替换分组.png) | 从原包开始，编号 2，选“替换分组”，数值 `0000`，点“对比解密” | P1 相同，P2、P3 改变，P4 起相同 |

最后两张使用放大的实际窗口，以便看清逐组对比。两次篡改不会叠加；完整差值见 [自动验证记录](results/五关测试结果.md)，原始包见 [cbc_cipher.json](results/cbc_cipher.json)。
