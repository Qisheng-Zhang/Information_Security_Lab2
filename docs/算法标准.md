# 算法标准与教材核对

依据：用户提供的《附录 D 简化 AES》扫描 PDF，表 D.1、图 D.1/D.2/D.4、D.3 节及附件 D.1。下文“PDF 第几页”从文件第一页起计，“印刷页”是纸面页码。主程序不依赖在线链接或 PDF 文件。

## 状态与位序

PDF 第 2 页，图 D.2：16 bit 从高到低拆为 `n0 n1 n2 n3`，按列放入：

```text
[ n0  n2 ]
[ n1  n3 ]
```

例如 `A749` 对应 `[A 4;7 9]`。PDF 第 3 页（印刷 507）轮密钥加的矩阵例子，按此位序写成整数为：

```text
A749 XOR 2D55 = 8A1C
半字节替代：8A1C -> 604C
行移位：    604C -> 6C40
列混淆：    6C40 -> 3743
```

不能把矩阵按行抄成 `A479` 后仍声称位序与图 D.2 一致。

## 替换表

PDF 第 4 页（印刷 508），表 D.1。输入高两位为行、低两位为列：

```text
S 盒                         逆 S 盒
9 4 A B                      A 5 9 B
D 1 8 5                      1 7 8 F
6 2 0 3                      6 0 2 3
C E F 7                      C 4 D E
```

代码将 S 盒按行展开为十六个值，逆表由置换自动求逆；测试逐项核对 PDF 正、逆表，避免“两个表互逆但一起抄错”的假通过。

## 密钥扩展

PDF 第 5 页（印刷 509），D.3 节：

```text
w0 = K[15:8]，w1 = K[7:0]
w2 = w0 XOR RCON(1) XOR SubNib(RotNib(w1))
w3 = w2 XOR w1
w4 = w2 XOR RCON(2) XOR SubNib(RotNib(w3))
w5 = w4 XOR w3
K0 = w0 || w1，K1 = w2 || w3，K2 = w4 || w5
RCON(1) = 80，RCON(2) = 30
```

教材例子 `K=2D55` 得到 `w2=BC, w3=E9, w4=A3, w5=4A`，因此轮密钥为 `2D55 BCE9 A34A`。

## 轮流程

加密按从左到右执行：

```text
XOR K0 -> NS -> SR -> MC -> XOR K1 -> NS -> SR -> XOR K2
```

解密按严格逆序执行：

```text
XOR K2 -> ISR -> INS -> XOR K1 -> IMC -> ISR -> INS -> XOR K0
```

SR 只交换第二行的两格，因此 SR 与 ISR 相同。最后一轮没有列混淆。教材另有等价逆密码的推导；本项目采用直接逆序形式，避免交换逆列混淆与密钥加时忘记变换轮密钥。

## GF(2^4) 与列混淆

PDF 第 4、7、8 页。加法为 XOR，乘法是多项式乘积模 `x^4+x+1`，即 `0x13`。矩阵为 `[1 4;4 1]`，逆矩阵为 `[9 2;2 9]`。教材附件算例 `4*C=5` 被纳入自动测试。

## 两份历史源码的差异

| 项目 | 本次 PDF / 当前 Python | 历史 C++ |
|---|---|---|
| S(3), S(4), S(5) | B, D, 1 | D, 1, B |
| 第二轮常量 | 30 | 80 |
| P=D6B3, K=A73B | C=000F | C=AFA2 |

原 Python 核心的主要参数与 PDF 一致；本次重写接口、校验、模式封装、GUI 与验证。历史 C++ 的自身往返测试通过，不代表它符合这份教材。用于本次交叉测试的新 C++ 参考实现已按 PDF 设置参数。

`6F6B/A73B/0738` 和 `D6B3/A73B/000F` 是项目回归向量，不能把它们描述为本次 PDF 中并未给出的完整加密算例。实际 PDF 的密钥扩展及各基本变换例子均有单独测试。
